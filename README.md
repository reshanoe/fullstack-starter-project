# Frontend – Next.js

## Setup

1. **Install dependencies:**

   ```sh
   npm install
   # or
   yarn install
   ```

2. **Configure environment:**

   - Copy `.env.example` to `.env` and set your variables if needed.

3. **Run development server:**

   ```sh
   npm run dev
   # or
   yarn dev
   ```

4. **Open app:**
   - Visit [http://localhost:3000](http://localhost:3000)

## Structure

- `src/app/` – Pages (login, register, users)
- `src/lib/axios.ts` – Axios instance for API calls
- `public/` – Static files

## Useful commands

- Build:
  ```sh
  npm run build
  ```
- Lint:
  ```sh
  npm run lint
  ```
